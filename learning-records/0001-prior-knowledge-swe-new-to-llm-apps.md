# Prior knowledge: strong software engineer, new to LLM application development

The learner is a working software engineer who has not yet built LLM-powered applications. Skip general programming explanations, use code freely, and start LLM material from first principles of system design (calls, tools, loops) rather than from API syntax. Target: applied LLM engineer role in 3-6 months at 4-7 hours per week.

## Implications
- Lessons can assume fluency with HTTP APIs, JSON, control flow, and testing.
- Do not assume any depth on prompting, tool use, retrieval, or evals until demonstrated.
